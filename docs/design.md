# Champions Club — Design System

## 1. Design Reference
The visual direction is inspired by the ISA Students' Chapter, Gujarat Section Nirma University website at https://isaitnu.org/.

The reference site uses a modern, editorial, technology-oriented presentation with strong hero messaging, large visual areas, concise navigation, numbered highlights, section-based storytelling, and a strong blue accent. Its visible content includes navigation such as Home, About, Events, Gallery, Team, Join Us, and Contact Us, plus large headline-driven sections and feature highlights. 

Reference: https://isaitnu.org/

## 2. Design Direction
Translate that visual language into a **premium sports-club management dashboard**, not a direct copy.

Keywords:
- Modern
- Premium
- Energetic
- Clean
- Technical
- Spacious
- Confident
- Data-driven

## 3. Color Direction
Use a mostly neutral interface:
- White / off-white surfaces
- Near-black/dark text
- Deep navy/blue accents
- Soft gray borders and backgrounds
- Blue for primary interactive elements
- Semantic success/warning/error colors only where needed

Avoid excessive gradients and excessive saturated colors.

## 4. Typography
Use a modern sans-serif typeface.

Hierarchy:
- Large bold hero/dashboard headline
- Medium section titles
- Compact labels
- Clear body text
- Monospaced or compact numeric styling may be used for KPI values

## 5. Navigation
Desktop:
- Persistent sidebar for authenticated staff
- Compact top bar for account/status/actions

Public website:
- Minimal top navigation
- Strong CTA for trial booking / joining
- Large hero section

## 6. Dashboard
Owner dashboard should prioritize:
- Revenue
- Court utilization
- Active members
- Shop sales
- Bar sales
- Outstanding invoices
- Low-stock products
- Recent bookings

Use cards, tables, charts, and activity feeds with generous spacing.

## 7. Booking UI
The booking screen should feel like a scheduling tool:
- Date selector
- Court selector
- Time grid
- Available/unavailable states
- Booking details panel
- Clear confirmation state

Do not hide important availability information behind excessive animation.

## 8. POS UI
The bar/POS screen should optimize for speed:
- Large category buttons
- Product/item cards
- Current order panel
- Table/tab indicator
- Discount visibility
- Payment action

## 9. Shop UI
Use product cards and inventory indicators:
- Product image
- Name
- Price
- Stock
- Low-stock badge
- Add/order action

## 10. Motion
Use GSAP or Anime.js selectively:
- Page transitions
- KPI number reveal
- Modal transitions
- Booking confirmation
- Subtle hover interactions

Animation must never interfere with fast operational workflows.

## 11. Responsive Design
The system should work across:
- Desktop
- Laptop
- Tablet
- Mobile for member-facing workflows

Staff/POS interfaces should prioritize larger screens.

## 12. Design Principle
The reference website is inspiration for **visual language**, not a component-by-component copy.

The product should feel like:
**"A professional sports club's operating system."**
